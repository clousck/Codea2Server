Para tenerlo en cuenta

  • La columna file es la clave: une cualquier tabla con sesiones.
  • pin es texto. En Excel abre el .xlsx: al abrir un CSV, Excel se come los ceros a la izquierda (0101 → 101).
  • Los CSV van con coma, punto decimal y UTF-8. Las banderas son 0/1 y lo que no aplica queda vacío.
  • Los tiempos van en segundos, redondeados a milésimas; las marcas …Utc, tal como las escribió el visor.
Descargar desde Python o R

Cualquier descarga admite autenticación básica: el usuario da igual y la contraseña es la del panel.

import io, requests, pandas as pd

url = "{{ url_for('exportar', name='sesiones', fmt='csv', _external=true) }}"
r = requests.get(url, auth=("codea", "LA_CONTRASEÑA"))
sesiones = pd.read_csv(io.BytesIO(r.content), dtype={"pin": str})
library(httr); library(readr)

r <- GET("{{ url_for('exportar', name='sesiones', fmt='csv', _external=true) }}",
         authenticate("codea", "LA_CONTRASEÑA"))
sesiones <- read_csv(content(r, "raw"), col_types = cols(pin = col_character()))
